# Agentic AI Web Scraping Platform

A backend platform that registers websites and target URLs, runs reusable scraping workflows over HTTP, prefers deterministic extraction, and uses LLMs only to discover, repair, or validate configurations.

## Stack

- **Language / Runtime**: Python 3.12.x (pinned `>=3.12,<3.13`), CPython
- **Framework**: FastAPI + Pydantic v2 (uvicorn ASGI, pydantic-settings for config)
- **Key dependencies**: SQLAlchemy 2 (async) + Alembic + asyncpg on PostgreSQL 16, httpx (http/2), selectolax, structlog, asgi-correlation-id
- **Package manager**: uv (lockfile authoritative, `pyproject.toml` carries minor pins)
- **Shape**: modular monolith, domain modules under `src/app/domains/`, infrastructure under `src/app/infrastructure/`, boundaries enforced by `import-linter`
- **Local data stores**: Docker Compose (Postgres only; app runs on the host)

## Build approach

**Skateboard**: ship the thinnest usable whole first, then grow it slice by slice. Workflow tier is **Beta** (`/develop` → `/check verify` → `/test`), unless a feature header tags otherwise.

## Rules

**Domain-Driven Design (modular monolith)**
- Code is organized by bounded context under `src/app/domains/{websites,workflows,executions,extraction,products,agents}/`. A domain module may import `core` and its own package only; cross-domain calls go through `core` or an event. Enforced by `import-linter`.
- Aggregates are the consistency boundary; only aggregate roots cross context lines, and only by ID.
- Use the ubiquitous language of the domain in names (classes, methods, variables).
- Value objects (e.g. `Money`, `URL`, `Selector`) are immutable and validated on construction; money is always `Decimal`, never `float`.
- Repositories abstract persistence: the domain layer defines the interface, `infrastructure/db` implements it.
- Application services (FastAPI routers + per-domain service modules) coordinate use cases only; domain logic lives in aggregates and domain services.
- Anti-corruption layers isolate external systems (LLM providers, legacy ADK agent, third-party sites) from the domain model.

**Project conventions**
- Typing: `mypy --strict` project wide; no `# type: ignore` without a code and a one-line reason.
- Identifiers: UUIDv7 primary keys; `TIMESTAMPTZ` columns, UTC, timezone-aware end to end.
- JSON wire format: snake_case fields; ISO-8601 datetimes with trailing `Z`; UUIDs as strings; money as `Decimal`.
- Errors: RFC 7807 Problem Details on every error path (`application/problem+json`, per-domain `code`, `correlation_id` extension).
- Correlation: `X-Request-ID` middleware bound to structlog contextvars; every request and execution log line carries it.
- Config: pydantic-settings reads `.env` locally and env vars in deployed envs; **validate at startup, fail fast**.
- API: `/api/v1/...` prefix; cursor pagination for executions and products, offset for small admin lists.
- Public APIs are documented: docstrings on public functions, classes, and FastAPI routes; OpenAPI stays accurate.
- SQLAlchemy: request-scoped `AsyncSession` via `Depends(get_session)`, `expire_on_commit=False`, explicit `selectinload` (no lazy I/O).
- Migrations: `YYYYMMDDHHMM_slug.py`; review every autogenerated migration by hand; never silently drop data.
- Reserved folders (`infrastructure/{cache,queues,observability}`, `domains/agents`) stay empty until their slice; no placeholder modules.
- Commits: Conventional Commits (`type(scope): subject`, e.g. `feat(workflows): …`).

## Tooling

- Lint + format: **ruff** (one tool). Config in `pyproject.toml`.
- Type check: **mypy strict**.
- Pre-commit: ruff (fix), ruff-format, mypy on `src/`, plus hygiene hooks (trailing whitespace, EOF, large files, private keys). Install with `uv run pre-commit install`.
- Testing: **pytest + pytest-asyncio (`auto`) + httpx `AsyncClient` + testcontainers (session-scoped Postgres)**. Each test runs in its own transaction and rolls back.
- Module boundaries: `import-linter` contracts in `pyproject.toml`.
- CI: lint + mypy + pytest + build on push (details owned by Scope Feature 28, not this doc).
